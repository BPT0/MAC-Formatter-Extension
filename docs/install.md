# 설치 안내 (팀원용)

MAC Formatter and Replacer를 스토어 없이 zip 파일로 설치하는 방법이다. 크롬의 **개발자 모드**로 폴더를 직접 로드한다.

## 준비물

- Chrome (버전 102 이상)
- 전달받은 `mac-formatter-<버전>.zip` 파일과, 함께 전달받은 SHA-256 체크섬

## 설치

1. **zip을 오래 둘 폴더에 푼다.** 예: `C:\Tools\MACFormatter`
   - 바탕화면, 다운로드, 임시 폴더에는 풀지 않는다. 폴더를 지우거나 옮기면 확장이 꺼진다.
   - 푼 폴더 바로 안에 `manifest.json`이 보여야 한다. 폴더 안에 같은 이름의 폴더가 한 번 더 있으면 안쪽 폴더를 선택한다.
2. 크롬 주소창에 `chrome://extensions`를 입력해 연다.
3. 오른쪽 위 **개발자 모드**를 켠다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 1번에서 푼 폴더를 선택한다.
5. 툴바의 퍼즐 아이콘을 눌러 **MAC Formatter and Replacer**를 고정(핀)한다.

받은 zip이 전달된 파일과 같은지 확인하려면 PowerShell에서 체크섬을 계산해 전달받은 값과 비교한다.

```powershell
Get-FileHash .\mac-formatter-1.0.0.zip -Algorithm SHA256
```

## 사용법

### 이미지로 받은 MAC 주소 복사
1. 확장 프로그램 아이콘을 눌러 팝업을 연다. 잠시 뒤 "준비 완료"가 표시된다.
2. 이미지를 복사한 뒤 팝업에서 `Ctrl+V`로 붙여넣는다. 이미지 파일을 끌어다 놓아도 된다.
3. 인식된 MAC 주소가 칩으로 표시된다. 칩을 누르면 클립보드에 복사된다. 옆의 작은 칩은 구분자 없는 번호(`005056AC5621`)다.
4. 밑줄 친 글자는 인식이 불확실하다는 뜻이다. 원본 이미지와 대조한 뒤 사용한다.
5. 인식이 안 되면 **영역 직접 선택**으로 번호가 있는 부분만 드래그해 다시 인식한다.
6. 구분자(`-`, `:`, 없음)와 대소문자는 칩 아래 옵션에서 고른다.
7. 팝업을 닫았다 다시 열어도 붙여넣은 내용은 브라우저를 닫을 때까지 유지된다. **모두 지우기**로 지울 수 있다.

이미지는 이 PC 안에서만 처리되며 외부로 전송되지 않는다.

### 직접 입력
팝업 가운데의 입력 칸에 번호를 넣고 **Format**을 누르면 지정한 형식으로 바꿔 복사한다. 12자리 16진수여야 한다. **지우기**로 입력과 결과를 지운다.

### 페이지의 번호 변환 (우클릭)
페이지에서 번호를 선택하고 우클릭 → **Format and Replace as MAC Address**를 누르면, 같은 줄의 입력 칸에 포맷된 번호가 들어가고 클립보드에 복사된다. MAC 주소가 아니면 "Invalid MAC Address"가 표시된다.

- 입력 칸이 선택한 번호와 같은 줄(`<p>` 안)에 있을 때 동작한다.
- 이 기능은 우클릭한 순간에만 현재 페이지에 접근한다. 모든 사이트에 상시 접근하지 않는다.
- 변환할 수 없는 영역이면 확장 아이콘에 빨간 `!` 배지가 잠깐 표시된다.

### 등록 오류가 났을 때 (insert 문 만들기)
1. 팝업 맨 아래 **혹시 등록 시 오류가 발생하였나요?**를 눌러 연다.
2. 위에서 MAC 주소를 인식하거나 직접 입력해 둔다.
3. 라이선스 키 입력 칸에 라이선스 키를 붙여넣는다.
4. 만들어진 insert 문 칩을 누르면 복사된다(키 입력 칸에서 `Enter`도 가능).
5. 서버 접속과 DB 접속은 직접 진행한다. 확장 프로그램은 insert 문만 만든다.

라이선스 키는 저장되지 않으며 팝업을 닫으면 사라진다. 사용하는 MAC은 이미지 인식 1순위와 직접 입력 중 가장 최근에 갱신된 값이고, 칩 위에 어느 쪽인지 표시된다.

## 업데이트

새 버전 zip을 받으면 다음 순서로 바꾼다.

1. 새 zip을 **기존과 같은 폴더**에 풀어 덮어쓴다.
2. `chrome://extensions`에서 이 확장의 **새로고침** 버튼을 누른다.

같은 폴더를 써야 확장 ID가 유지된다. 다른 폴더에 풀면 별도 확장이 하나 더 생기니 기존 것을 **제거**한다. 자동 업데이트는 없다.

## 문제 해결

| 증상 | 확인 |
|---|---|
| 로드할 때 "매니페스트 파일이 없거나 읽을 수 없습니다" | 선택한 폴더 바로 안에 `manifest.json`이 있는지 확인한다(폴더가 한 겹 더 있는 경우가 많다) |
| 팝업이 "모델을 불러오지 못했습니다"라고 표시 | 확장을 새로고침하고, 폴더의 `vendor/onnx` 안 파일이 모두 있는지 확인한다 |
| 칩을 눌러도 복사가 안 됨 | 팝업을 닫았다 다시 열고 다시 누른다. 계속되면 오류 내용을 전달한다 |
| 우클릭 변환이 안 되고 `!` 배지가 뜸 | 그 페이지(프레임)에서는 변환할 수 없는 영역이다. 팝업의 직접 입력을 쓰고, 페이지 주소와 함께 알려 준다 |
| 크롬을 켤 때 개발자 모드 확장 안내가 뜸 | 개발자 모드로 로드한 확장에서 나타나는 안내다. 확장을 유지하는 쪽을 선택한다 |
| 조직 정책으로 개발자 모드를 켤 수 없음 | 이 방식으로는 설치할 수 없다. 배포 담당자에게 알린다 |

문제가 생기면 `chrome://extensions`의 이 확장 카드에서 **오류** 버튼 내용, 또는 팝업을 오른쪽 클릭 → **검사** → 콘솔의 오류 문구를 함께 전달한다.

## 제거

`chrome://extensions`에서 이 확장의 **제거**를 누르고, 풀어 둔 폴더를 지운다.

## 배포 담당자용

새 zip을 만들 때는 저장소 루트에서 실행한다.

```powershell
powershell -ExecutionPolicy Bypass -File tools/package.ps1
```

- 결과: `dist/mac-formatter-<manifest 버전>.zip`
- 스크립트가 모든 사이트 접근 설정, 번들 파일 체크섬, 외부 스크립트 여부를 검사한다.
- 새로 배포할 때는 `manifest.json`의 `version`을 먼저 올린다(예: `1.0.1`).
- zip과 함께 SHA-256 체크섬을 전달하고, 배포한 버전과 날짜를 기록해 둔다.
