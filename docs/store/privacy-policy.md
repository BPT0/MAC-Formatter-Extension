## 한국어

1. **수집하는 정보**: 이 확장 프로그램은 개인정보를 수집하지 않으며 개발자나 제3자의 서버로 어떤 데이터도 전송하지 않습니다.
2. **이미지 처리**: 팝업에 붙여넣은 이미지는 사용자의 PC 안에서만 처리됩니다. 글자 인식에 쓰는 코드와 모델은 확장 프로그램에 포함되어 있으며, 인식 중에 인터넷에 접속하지 않습니다.
3. **임시 보관**: 팝업을 닫았다 다시 열어도 이어서 볼 수 있도록 붙여넣은 이미지, 인식 결과, 직접 입력한 번호를 브라우저의 세션 저장소(`chrome.storage.session`, 메모리)에 보관합니다. 이 내용은 브라우저를 닫으면 삭제되며, 팝업의 "모두 지우기" 버튼으로 언제든 지울 수 있습니다.
4. **설정 저장**: 구분자와 대소문자 선택값은 확장 프로그램 페이지의 로컬 저장소에 저장됩니다.
5. **권한 사용**: 우클릭 메뉴를 눌렀을 때만 현재 탭에 접근해 선택한 번호를 변환하고, 변환 결과를 클립보드에 씁니다(클립보드를 읽지 않습니다).
6. **제3자 제공 / 광고 / 분석**: 없습니다. 사용자 데이터를 판매하거나 광고, 분석 목적으로 사용하지 않습니다.
7. **변경**: 방침이 바뀌면 이 문서를 갱신하고 시행일을 고칩니다.

## English

1. **Data collected**: This extension does not collect personal data and does not send any data to the developer or any third party.
2. **Image processing**: Images pasted into the popup are processed only on your computer. The code and models used for text recognition are bundled with the extension, and no network access happens during recognition.
3. **Temporary storage**: So the popup can resume after being closed, the pasted image, recognition results, and typed number are kept in the browser's session storage (`chrome.storage.session`, in memory). This data is deleted when you close the browser, and you can clear it at any time with the "Clear all" button in the popup.
4. **Settings**: Your separator and letter-case choices are stored in the extension page's local storage.
5. **Permissions**: The extension accesses the current tab only when you click its context-menu item, converts the selected number, and writes the result to the clipboard (it never reads the clipboard).
6. **Third parties / ads / analytics**: None. Your data is not sold and is not used for advertising or analytics.
7. **Changes**: If this policy changes, this document is updated together with the effective date.
