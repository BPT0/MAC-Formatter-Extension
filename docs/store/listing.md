# 스토어 등록 정보 (초안)

대시보드의 **스토어 등록정보** 탭에 넣을 내용이다. 확정 전에 회사 승인(브랜드 표기 등)을 거친다.

## 기본 정보

| 항목 | 값 |
|---|---|
| 이름 | MAC Formatter and Replacer |
| 요약(manifest `description`, 132자 이하) | Reads MAC addresses from pasted images on your PC (no upload) and formats selected text, then copies in any format. |
| 카테고리 | 생산성 (Productivity) |
| 언어 | 한국어 (설명문은 한국어, 요약은 manifest의 영어 문구가 사용됨) |
| 지원 이메일 | (사용자가 입력) |
| 개인정보 처리방침 URL | (게시 후 입력, `privacy-policy.md` 참고) |

## 자세한 설명 (한국어)

```
이미지로 받은 MAC 주소를 직접 타이핑하지 않고 바로 복사하세요.

■ 이미지에서 MAC 주소 인식
- 확장 프로그램 아이콘을 누르고 이미지를 붙여넣으면(Ctrl+V) MAC 주소를 찾아 칩으로 보여 줍니다.
- 칩을 누르면 포맷된 번호(예: 00-50-56-AC-56-21)가 클립보드에 복사되고, 옆의 칩으로 구분자 없는 번호(005056AC5621)도 복사할 수 있습니다.
- 인식이 불확실한 글자는 밑줄로 표시되고, 필요하면 영역을 직접 지정해 다시 인식할 수 있습니다.
- 인식은 모두 이 PC 안에서 처리합니다. 이미지는 어디로도 전송되지 않습니다.

■ 선택한 텍스트를 MAC 형식으로 변환
- 페이지에서 번호를 선택하고 우클릭 → "Format and Replace as MAC Address"를 누르면 같은 줄의 입력 칸에 포맷된 번호를 넣고 복사합니다.
- 12자리 16진수가 아니면 "Invalid MAC Address"로 알려 줍니다.

■ 직접 입력
- 팝업의 입력 칸에 번호를 입력해 구분자(-, :, 없음)와 대소문자를 골라 복사할 수 있습니다.

■ 개인정보
- 이미지와 인식 결과는 브라우저 메모리에만 임시로 보관되며 브라우저를 닫으면 사라집니다. 외부 서버로 보내지 않고, 분석 도구도 사용하지 않습니다.
- 인식 모델과 코드는 모두 확장 프로그램에 포함되어 있습니다(원격 코드 없음).

인식 결과는 틀릴 수 있으니 이미지와 대조한 뒤 사용하세요.
```

## 스토어 이미지 체크리스트

([규격](https://developer.chrome.com/docs/webstore/images))

- [ ] 스크린샷 1280×800 (1~5장): 붙여넣기 → 인식 칩 / 영역 직접 선택 / 직접 입력. **사내 이미지 대신 `sample-mac-image.png` 같은 합성 이미지**를 쓴다.
- [ ] 작은 홍보 이미지 440×280
- [ ] 아이콘 128×128 PNG: 그림 96px + 사방 약 16px 투명 여백인지 `icons/icon128.png` 확인
- [ ] (선택) 마키 1400×560
