# 개인정보 탭 입력 내용 (초안)

대시보드의 **개인정보 보호관행** 탭에 넣을 내용이다 ([필수 항목 안내](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy)). 코드를 바꾸면 이 문서도 함께 고친다.

## 단일 목적

```
MAC 주소를 지정한 형식(구분자, 대소문자)으로 변환해 클립보드에 복사한다. 입력 방법은 페이지에서 선택한 텍스트, 직접 입력, 붙여넣은 이미지 세 가지다.
```

## 권한 사유

| 권한 | 사유 (대시보드에 입력) |
|---|---|
| `contextMenus` | 텍스트를 선택하고 우클릭했을 때 "Format and Replace as MAC Address" 메뉴를 보여 준다. |
| `activeTab` | 사용자가 위 메뉴를 눌렀을 때만 현재 탭에 일시적으로 접근한다. 모든 사이트에 상시 접근하지 않는다. |
| `scripting` | 사용자가 메뉴를 누른 프레임에만 `content.js`를 주입해 선택한 번호를 포맷하고 입력 칸에 넣는다. |
| `clipboardWrite` | 변환한 MAC 주소를 클립보드에 복사한다. 읽기는 하지 않는다. |
| `storage` | 팝업을 닫았다 다시 열어도 붙여넣은 이미지와 인식 결과를 이어서 볼 수 있도록 `chrome.storage.session`(브라우저 메모리, 브라우저를 닫으면 삭제)에 임시 보관한다. |

호스트 권한(`host_permissions`)과 상시 실행 콘텐츠 스크립트는 없다.

## 원격 코드

**"원격 코드를 사용하지 않음"을 선택한다.**

- 모든 JavaScript, WebAssembly, 모델 파일(ONNX)이 확장 프로그램 패키지 안에 있다. 출처, 버전, 체크섬은 `vendor/onnx/README.md`, `vendor/onnx/SHA256SUMS`, `THIRD_PARTY_NOTICES.md`에 있다.
- CSP의 `'wasm-unsafe-eval'`은 패키지에 포함된 ONNX Runtime(WebAssembly)을 실행하기 위해서만 필요하다. 외부에서 받은 코드를 실행하지 않는다.
- `popup.html`은 외부 주소의 스크립트를 불러오지 않는다 (`tools/package.ps1`이 패키징할 때 확인한다).

## 데이터 사용 공개

- 이 확장 프로그램은 사용자 데이터를 **개발자나 제3자에게 전송하거나 수집하지 않는다.**
  - 붙여넣은 이미지는 PC 안에서만 처리하고, 이미지와 인식 결과는 브라우저 메모리(`chrome.storage.session`)에만 임시 보관한다.
  - 분석 도구, 광고, 원격 로깅이 없다.
  - 포맷 옵션(구분자, 대소문자)은 확장 페이지의 `localStorage`에 저장한다.
- 대시보드의 데이터 유형 체크 항목은 위 사실에 맞게 입력하고, 아래 인증 문구에 동의한다.
  - 승인된 용도 외에는 사용자 데이터를 판매하거나 이전하지 않는다.
  - 확장 프로그램의 단일 목적과 무관한 용도로 사용자 데이터를 사용하지 않는다.
  - 신용도나 대출 목적으로 사용하지 않는다.
- 확인 필요: 대시보드가 "수집"을 어떻게 정의하는지(기기 밖으로 전송되는 경우만인지)는 이 문서 작성 시점에 공식 문서로 확정하지 못했다. 입력 화면의 안내를 읽고 체크 항목을 정한다.

## 개인정보 처리방침

`privacy-policy.md`를 공개 URL에 게시하고 그 주소를 입력한다.
